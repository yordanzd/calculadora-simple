# Calculadora Simple

Una calculadora básica para realizar operaciones matemáticas, construida con HTML, CSS y JavaScript vanilla.

## Descripción

Calculadora Simple permite realizar las cuatro operaciones matemáticas básicas (suma, resta, multiplicación y división) a través de una interfaz visual inspirada en las calculadoras tradicionales, con un diseño oscuro personalizado.

## Características

- 🔢 Botones numéricos del 0 al 9 y punto decimal
- ➕➖✖️➗ Operaciones básicas: suma, resta, multiplicación y división
- ⚙ Cálculo de resultados con el botón "="
- 🧹 Botón para limpiar la operación actual
- 🎨 Diseño personalizado con variables CSS (paleta de colores propia)

## Estructura del proyecto

```
calculadora/
├── index.html    # Estructura de la página
├── styles.css    # Estilos y paleta de colores
└── script.js     # Lógica de la calculadora
```

## Tecnologías utilizadas

- HTML5
- CSS3 (variables CSS / custom properties, Grid)
- JavaScript (vanilla, sin frameworks)

## Cómo usar

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Haz clic en los números y operadores para construir tu operación.
4. Presiona "=" para ver el resultado.
5. Presiona "C" para limpiar y empezar de nuevo.
